01 / 收音

离声音更近一点。

用 iPhone 作为 Mac 的麦克风，也可以直接使用电脑、耳机或外接麦克风。

02 / 输入

留在熟悉的输入位置。

在 Mac 选择输入框，再开始说话。识别与文字输入由 Mac 端完成。

03 / 声音

把注意力放在你身上。

可选声纹过滤，在自己的 Mac 上登记和判断说话人。它不能分离同时重叠的人声。
