There is no App Store purchase link or public TestFlight invitation yet.

A few things to check first.

  • You need a compatible Mac. The iPhone audio and text-input workflow requires the Mussito Mac app.
  • For first-time pairing, use the same local network on both devices and keep your Mac awake.
  • Local recognition requires an initial model download. The mode that uses an installed input method needs its audio channel configured.
  • Intel Macs are not yet part of the initial hardware validation. More compatibility details will accompany the public release.
