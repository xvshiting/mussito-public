隐私政策

了解声音，
经过哪些地方。

更新日期：2026 年 10 月 16 日。适用于 Mussito iPhone 端、Mac 端及本官网。

Mussito 由独立开发者维护，提供 iPhone 与用户自己的 Mac 之间的语音输入体验。你可通过本页末尾的 GitHub 入口联系维护者。本政策会随正式发布功能更新。

1. iPhone 与自己的 Mac

iPhone 在你授权麦克风并开始会话后采集音频，通过加密连接发送给已配对的 Mac。首次配对需要扫描二维码或使用配对链接，本地网络权限用于发现和连接设备。iPhone 不直接调用 Mac 端所选择的识别软件或服务。

普通语音输入的音频只用于当前会话，Mussito 不将其保存为录音文件，也不将音频或识别正文写入正常运行日志。Mussito 没有用于接收或保存用户语音的自营云端识别服务器。

2. Mac 端处理与文字输入

音频在 Mac 端按你的设置经过人声检测、可选声纹过滤与识别。本地识别模式由 Mac 上的模型处理；准备模型时需连接模型下载服务，下载提供方可能按其自身政策处理下载连接信息。

如果你在 Mac 选择使用已安装的其他输入法或识别软件，获准的音频会交给该软件。是否联网以及该软件如何处理数据，取决于你的选择、软件设置和对应的隐私政策。请在 Mac 端使用前了解其说明。

识别文字会写入你选择的 Mac 应用。文字进入目标应用后的保存、同步与分享由该应用及你的设置决定。本地识别的文字输入可能短暂使用系统剪贴板；在剪贴板未被其他操作更改时，应用会尝试恢复原内容。

3. 配对资料与设备信息

配对凭据保存在设备的系统钥匙串中，用于验证自己的设备。连接所需的地址、服务标识、设备名称和偏好保存在设备本地。配对链接含有访问凭据，请不要公开分享；你可以在 Mac 设置中重置配对，使旧凭据失效。

4. 可选的声纹过滤

启用声纹功能时，登记录音用于在 Mac 上生成声纹向量。向量保存在 Mac 本机，Mussito 不向开发者服务器上传声纹资料，也不保留登记录音文件。你可以在 Mac 设置中删除或重新登记声纹。

5. 权限、选择与删除

你可以在 iPhone 或 Mac 的系统设置中撤销麦克风、本地网络、辅助功能与输入监控权限；相关功能可能因此不可用。停止会话或取消会停止后续处理，已经输入到目标应用的文字需要在目标应用中自行删除。

删除应用不一定自动删除 Mac 上的本地资料、钥匙串凭据或已安装的音频组件。需要移除时，请先删除声纹、重置配对，并按 Mac 音频组件的卸载说明操作。对本地数据处理有疑问，可通过支持入口联系维护者。

6. 本官网与公开反馈

本官网通过 GitHub Pages 提供，没有加入广告、访客分析脚本或用于跟踪用户的 Cookie。GitHub 作为托管服务提供方，可能按照其隐私声明处理访问所需的网络与日志信息。

通过 GitHub 提交反馈时，GitHub 按其政策处理账号和反馈信息。公开 Issue 的内容可被任何人查看，请不要附上配对二维码、密钥、私人录音或未处理的私人文本。Mussito 不会自动上传诊断报告；你可自行决定是否提交已检查的说明和截图。

7. 购买与更新

iPhone 端正式通过 App Store 提供后，购买由 Apple 处理。开发者不会接触你的银行卡等付款信息。正式版如增加购买验证或改变数据处理方式，将同步更新本政策。

8. 联系与政策变更

隐私相关问题可通过GitHub 隐私问题入口联系维护者。此入口是公开的，先描述问题类型即可，不要提交敏感资料。政策变更会更新本页日期；涉及新增数据处理的变化，会在相应功能提供时说明。
